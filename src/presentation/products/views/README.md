# Vista del detalle

[Detalle](../README.md) → [product.hbs](product.hbs). La plantilla contiene contenido público, variantes iniciales deshabilitadas y puntos de unión `data-product-*` para el cliente.

No ejecutar lógica de selección ni incrustar JSON en scripts. Compartir [cabecera y pie](../../shell/README.md) y [panel de carrito](../../cart/views/partials/cart-panel.hbs); IDs de galería y formularios deben ser únicos.
