# Estado del desarrollo

Este repositorio contiene una base de tienda en desarrollo; **no está lista para producción ni para recibir datos o ventas reales**.

- El storefront permite una vista de demostración explícita en desarrollo. Sus imágenes generadas, productos y precios de ejemplo son sintéticos: no representan inventario real. En modo catálogo usa la API y no reemplaza errores con datos ficticios.
- Hay código para catálogo público y administrativo, identidad y sesiones administrativas; su presencia no equivale a una validación integral para producción.
- Pagos, envíos, pedidos, carga de medios e inventario/disponibilidad no están completos. El carrito visual no finaliza compras.
- Siguen pendientes las pruebas con MySQL real y la validación integral en navegador del sistema conectado. Revisar migraciones, seguridad y operaciones antes de cualquier uso real.
- La imagen de [diseño aprobada](design/propuesta-tienda-3d-color-desktop-mobile.webp) documenta la propuesta visual coral, azul cobalto y crema para escritorio y móvil. Es una conversión WebP sin pérdida de la imagen aprobada; el arte de demostración no es inventario.

Ver también el [README principal](../README.md), [la documentación del storefront](../apps/web/README.md) y [el estado de identidad](identity-status.md).
